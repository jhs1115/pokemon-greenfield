# 관동지방 1~5장 — 콘셉트와 전체 대본

현재 게임 반영본 기준. [대괄호]는 빨간 강조, 작은따옴표는 회색 생각/행동 표현이다. {파트너}는 선택한 스타팅 이름으로 바뀐다.

전체 방향: 배지 8개를 모아 챔피언에 도전하는 여정과 로켓단 사건을 병행한다. 뮤츠와 비주기는 장기 구상의 중심이지만 1~5장 대사에서는 이름을 직접 밝히지 않는다.

## 1장 — 모험의 시작

콘셉트: 태초마을·회색시티. 파트너를 얻고 배틀과 동료 모집을 자연스럽게 익힌다. 웅이와 주인공의 개그 사이에 굉음·쓰러진 트레이너·미지의 생물이라는 단서를 넣는다.

### 태초마을 연구소

이곳은 포켓몬 세계. 포켓몬이라 불리는 생물들과 사람이 공존하며 살아간다.

동시에 포켓몬끼리 싸우는 포켓몬 배틀은 이 세계의 문화로 자리 잡았으며,

이렇게 배틀을 하는 사람들을 "트레이너"라고 부른다.

모든 리그를 제패한 포켓몬 챔피언이 된다는 것은 모든 트레이너들의 꿈이다.

그렇기에 주인공은 오늘, 포켓몬 챔피언이 되러 오박사를 찾아간다.

주인공: “박사님!”

오박사: “왔구나! 기다리고 있었단다.”

주인공: “오늘 드디어 포켓몬을 받을 수 있는 거죠?”

오박사: “그렇단다. 이제 어엿한 성인이 되었으니 트레이너의 길을 걸을 수 있게 되었단다.”

오박사: “포켓몬은 세 마리 준비해 놨다. 어떤 포켓몬을 선택하겠니?”
