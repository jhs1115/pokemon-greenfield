# 게임 규칙과 자료 기준

## 저장과 호환

브라우저 localStorage의 기존 파일 1~3(`greenfield-slot-v2-*`)을 유지합니다. 10개였던 클리어 배열을 40개로 확장하고 기존 기록/잔액/포켓몬을 보존합니다. `?profile=qa-*` 검증 프로필은 별도 저장 키를 씁니다. 자동 저장이며 다른 브라우저/주소는 저장 공간이 다릅니다.

웅이 클리어 기록이 있지만 도구 해금 안내를 보지 않은 기존 파일은 메인 진입 시 안내가 뜹니다. 학습장치 두 개는 해금 플래그와 함께 한 번 지급되고, 안내 확인 여부는 별도로 저장되어 새로고침해도 중복 지급하지 않습니다.

## 시작과 성장

스타팅은 파이리/꼬부기/이상해씨 Lv.5입니다. 오박사 대사는 한 글자씩 표시하고 Enter로 완성/다음 대화를 진행합니다. 더미전 → 무료 연습 스카우트 → 동료 선출 → 기술 설정을 직접 해보는 튜토리얼이며, 완료/스킵 최초 1회에 10코인을 지급합니다. 신규 잔액은 0입니다.

성장/레벨업 기술은 PokéAPI의 FRLG(version group 7) 자료, 실제 6개 성장 곡선과 1세대 안의 실제 진화 조건을 사용합니다. 초기 기술은 이상해씨 몸통박치기/울음소리, 파이리 할퀴기/울음소리, 꼬부기 몸통박치기/꼬리흔들기입니다. IV31/EV0/성격 보정 1배이며 성장 시 HP 증가분을 현재 HP에 더합니다. 돌/통신 진화는 관리 버튼으로 수행하고 현재 도구 재고/거래 비용 없이 제공하는 프로토타입 동작입니다.

최대 3마리 선출·1마리씩 출전합니다. 기술은 최소 1개/최대 4개, 중복 불가입니다. 비최종 진화는 현재 레벨까지의 레벨업 기술 및 실제로 배웠던 기술만, 1세대 범위의 최종 진화 종은 자료가 존재하는 최신 공개 습득표의 모든 방법을 허용합니다. 특성은 진화 전 첫 일반 특성 고정, 최종 진화 후 해당 종의 일반/숨겨진 특성 선택입니다.

## 4장 캠페인

| 장 | 지도 | 관장 | 진행 |
|---|---|---|---|
| 1 | 초록 숲길 | 1-10 웅이 | 관동 초반 포켓몬, 도구 해금 |
| 2 | 강가의 산책로 | 2-10 이슬이 | 강가/동굴/주변 도로 포켓몬, 2-5 후 로켓단 습격 |
| 3 | 항구와 도시 | 3-10 마티스 | 진화형과 체급 높은 종도 등장, 3-3·3-8 로켓단 |
| 4 | 꽃과 숲의 정원 | 4-10 민화 | 더 강한 진화형과 다양한 타입 |

각 장은 10개 스테이지이며 네 지도의 노드 좌표와 굽은 길이 다릅니다. 순서대로 해금되고 장을 모두 깨면 우측 상단의 다음 스테이지 버튼으로 이동합니다. 본격적인 스토리 본문은 이후 작성할 수 있도록 전투/관장/로켓단 조합을 분리했습니다. 적 구성은 본가 관동 진행에서 영감을 받은 이 게임의 조합이며 원작 모든 조우/레벨을 그대로 복제한 표는 아닙니다.

2-5 첫 승리 후 로켓단 꼬렛 진화형/주뱃/또가스 3마리(Lv.18/19/19)를 상대해야 2-6이 열립니다. 습격은 저장되어 나갔다 돌아와도 지도에서 다시 도전할 수 있습니다. 패배 시 로켓단을 재도전하고, 최초 승리 보상 4코인은 한 번만 받습니다. 3-3/3-8은 로켓단의 독/노말/비행 계열 팀입니다.

체육관은 원본 관장 도트+각 테마의 전용 배경을 사용합니다. 첫 방문은 세 대사 후 시작, 다음 방문부터는 한 대사 후 시작합니다. 대사는 현재 최소 전투 안내이며 원작 대사를 복사하지 않았습니다. PVP는 공사중입니다.

## 도구 / 학습장치

웅이 첫 클리어 직후 메인으로 돌아와 어두운 배경의 도구 해금 안내가 뜹니다. 오박사가 학습장치 2개를 지급합니다. 관리에서 왼쪽 포켓몬을 선택하고 지닌 도구를 고릅니다. 포켓몬당 1개이며 장착 시 재고가 줄고 해제/교체 시 돌아옵니다. 진화해도 장착을 유지합니다.

초기 드롭은 오랭/상태 회복 열매, 2장 이후 자뭉열매/실크스카프/목탄/기적의씨/신비의물방울/자석/딱딱한돌/예리한부리, 3장 이후 먹다남은음식도 포함합니다. 실제 회복·상태 해제·타입 강화·턴 종료 회복은 시뮬레이터가 처리합니다. 소비된 열매는 장착에서 제거되어 저장되고, 비소모성 도구의 전투 중 무효화/떨굼은 영구 재고 삭제로 처리하지 않습니다.

학습장치는 FRLG 방식으로 별도 성장 모델에서 처리합니다. 생존 참여자가 전체 경험치의 절반을 나누고 생존 착용자들이 나머지 절반을 나눕니다. 참여자이면서 착용자이면 양쪽 몫을 받습니다. 착용자가 없으면 기존처럼 생존 참여자끼리 모두 나눕니다. 경험치는 `floor(종별 FRLG expYield × 적 레벨 × 트레이너 보정(1 또는 1.5) × 배분 가중치 / 7)`입니다. 엔진에는 지닌 도구 슬롯을 유지하는 Exp. Share 정의를 추가하되 경험치 계산은 이 성장 모델에서만 수행합니다.

|---|---|---|---|
| 1 | 2 | 5 | 1 |
| 2 | 3 | 8 | 2 |
| 3 | 4 | 11 | 3 |

나머지 반복 승리는 코인 0입니다. 도구 해금 후 승리마다 장별 22.5%/25%/27.5%/30% 확률로 도구 1개를 받습니다. 배틀 ID 중복 정산을 막습니다. 기존 잔액과 이미 받은 최초 보상을 소급 변경하지 않습니다.

## 스카우트

10코인으로 기본형 후보 세 마리 중 한 마리를 선택합니다. 영입 레벨은 처음 5, 1장 완료 후 8, 2장 완료 후 12입니다. 해당 레벨의 실제 기본 기술로 시작합니다. 후보는 클릭 즉시 짧은 등장 애니메이션과 함께 표시하며 새로고침해도 유지되고 중복 비용을 내지 않습니다.

전설/환상(프리져/썬더/파이어/뮤츠/뮤)은 제외합니다. 현재 1세대 안의 기본형만 등장하고 이미 보유한 진화 계열은 제외합니다. 피츄 등 1세대 밖 아기 포켓몬은 추가하지 않습니다. 1세대 안의 무진화·종족값450 이상 종은 1장 완료 후 해금합니다. 스타팅 3종 및 미뇽(1세대 600족 계열)은 레어로 표시하고 종별 추첨 가중치 0.2, 일반은 1을 적용합니다. 3후보는 중복 없이 가중 추첨하므로 카드당 고정 확률이 아닌 상대 가중치입니다.

## 타일 / 전투

동시 선택 → 교체 → 모두 스피드 순 이동 → 기술 우선도/스피드 순 공격 → 기절 교대/정산입니다. 인접 8방향 한 칸 또는 현재 칸에 머무릅니다. 전투 중 선출 관리 메뉴는 없습니다. 사거리(청록), 타격(주황), 중심 급소(분홍)가 미리보기와 실제 판정에 같은 함수를 사용합니다.

타격은 최대 5칸입니다. 3×3은 십자 5칸, 직선은 일반적으로 길이5/폭1, 부채꼴은 1+3+1, 대각선은 중심+대각선 네 칸, 고리는 중심+두 칸 떨어진 네 방향입니다. 맵 경계는 잘립니다. 초반 공격은 1~3칸으로 작게 설정합니다(물대포/덩굴채찍 직선2 등). 상대 대상 변화기는 최소 사거리3, 실뿜기는 직선5이고 자기 자신 기술은 기존대로입니다. 추후 전용기는 `tileLimit` 명시 설정으로 분리할 수 있습니다.

물리/특수/변화는 버튼과 트레이닝 목록에 표시됩니다. 실제 전투 판정은 `@pkmn/sim` 0.10.12의 9세대 싱글 엔진입니다. 명중·회피, CC, 확률 부가 효과, 특성, 도구, 충전/반동 턴, 기습·기선제압 등의 조건을 처리합니다. 성장/원작 습득표는 FRLG이므로 게임 전체를 특정 본가 한 버전 그대로 재현한 것은 아닙니다.

랜덤 급소 대신 타격 중심에서 1.5배 급소를 판정하며 불리한 공격/방어 랭크를 무시합니다. 급소 방지 특성 등 실제 방어 효과는 계속 적용됩니다. 원작에는 타일 이동이 없으므로 이동과 사거리/범위는 독자 규칙입니다. 실제 계산 기록을 행동별로 재생하여 부드러운 이동/효과/피해를 순서대로 보여줍니다.

## 화면 / 소리

기술 실행 시 사용자 머리 위에는 기술 이름만, 피해·상성·랭크·상태 메시지는 해당 타일과 상단, 공지형 특성은 왼쪽 배너로 표시합니다. 기존 151종의 원본 애니메이션 GIF를 사용하며 NPC는 가벼운 호흡/흔들림 효과를 갖습니다. 눈 위치를 임의로 그려 고친 포켓몬은 없습니다. 진화는 기존 도트의 빛/흰 실루엣 전환 후 새 모습 공개입니다. 반복 CSS 동작은 움직임 줄이기를 존중합니다.

시작/메인 풍경, 스카우트 가게/트레이닝 실/체육관은 생성한 환경 이미지이며 포켓몬/관장/오박사는 기존 도트입니다. 스카우터는 사용자 요청으로 만든 오리지널 여성 NPC입니다. 화면 전환은 교체 전 화면을 먼저 확보한 뒤 220ms 동안 사라지며 새 화면을 보여줍니다. 교체 후 블러는 없습니다. 전투는 기존 단순한 풀숲 타일과 원본 PNG를 쓰고 타일을 정사각형으로 고정합니다. 기술 카드 속성 배지는 오른쪽 위, 기술명과 분류/PP는 별도 행으로 배치합니다. 관리/메인 UI는 밝은 크림/세이지 색조로 정리했습니다.

음악 기본 6%에 추가 감쇠, 효과음 18%입니다. 메뉴는 이전 Quiet Village, 전투/모든 관장전/로켓단은 실제 포켓몬 RBY 트레이너전 곡 하나입니다. 다운로드한 669개 PRSFX 기술음을 연결하고 없는 기술은 같은 속성의 파일을 공유합니다. 확인음 이외의 UI/대사/이동/울음/승리 소리는 껐습니다. 기술음은 한 번에 하나만 재생하며 피크 감쇠·리미터·짧은 페이드로 겹침과 급격한 끊김을 줄였습니다. 작은 **♪ → 음원 출처**에서 원문 출처를 확인합니다.

상대도 동일한 본가 특성 판정을 적용하며 교체 시 위협·흡수·면역 등 양쪽 특성 로그를 표시합니다. 배너는 ‘포켓몬의 특성 이름’만 표시하며 아군은 왼쪽, 상대는 오른쪽입니다. 잠듦/얼음은 해당 턴 이동 불가입니다. 잠깨기/해동은 공격 시 본가 판정이므로 깨어난 턴에도 이미 지나간 이동을 소급하지 않습니다. 마비는 독자 규칙으로 12.5%이며 턴당 한 번 뽑은 결과를 이동과 공격에 공유합니다. 교체는 상태이상 이동 제한에 막히지 않습니다.

관장 네 명의 기술은 `pret/pokefirered/src/data/trainer_parties.h`의 FRLG 첫 도전 기술 구성을 그대로 사용합니다. 레벨은 캠페인 난이도의 기존 레벨을 유지합니다. 적 AI는 사용 가능한 레벨업 기술 중 공격과 변화기를 함께 구성하고 상성·특성 면역·명중·회복·중복 상태·과도한 랭크 반복과 거리를 고려합니다. 플레이어가 선택한 이동/기술을 미리 읽지는 않습니다.

3장부터 기존 도구 보상 후보에 달의돌/불꽃의돌/천둥의돌/물의돌/리프의돌을 추가합니다. 관리의 도구 탭에서 돌을 고르고 ‘도구 사용’을 누른 뒤 엔트리의 알맞은 포켓몬을 선택하면 하나를 소모하며 진화하고 돌을 지닌 도구로 남기지 않습니다. 이미 보유한 진화형으로 덮어쓰기는 막습니다. 3~4장의 처치 경험치는 기본 공식에 1.5배를 적용하며 학습장치 분배는 동일합니다. 2-5 승리창의 ‘확인’을 누르면 로켓단이 등장합니다.

포켓몬 관리는 포켓몬/도구 두 탭으로 나뉩니다. 도구 탭은 가방과 엔트리로 구성하며, 도구 선택 → 도구 착용 또는 도구 사용 → 엔트리 대상 선택 순서입니다. 진화의 돌은 사용만, 지닌 도구는 착용만 가능합니다. 기존 착용 도구는 교체/해제 시 가방에 반환하며 진화해도 유지합니다. 2~4장 지도는 노드 좌표를 바꾸지 않고 각 노드 중심을 직선으로 연결합니다.
