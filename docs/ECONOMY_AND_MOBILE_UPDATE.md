# 재화 · 난이도 · 모바일 전장 개편 (2026-11-12)

- 저장 필드 coins는 호환을 위해 유지하되 화면은 쉼표와 원으로 표시한다. 기존 잔액은 최초 로드 때만 1,000배 환산하며 economyVersion=1과 story.seen의 economy-money-v1로 이중 환산을 막는다. 파일·보상·상점의 표시도 일치한다.
- 시작 소지금 0원, 출발 보상 10,000원. 기존 지급 여부를 유지한다.
- 반복 기본 상금: 1,000 + (장-1)×5,000 + (스테이지-1)×500원. 관장전은 2,000원 추가.
- 최초 추가 상금: 일반 2,000 + 장×1,000 + (스테이지-1)×500원, 관장 10,000 + 장×3,000원. 동일 전투의 중복 수령은 차단한다.
- 티켓 30,000원, 일반 열매 8,000원, 자뭉열매 15,000원, 타입 강화 도구 40,000원, 돌/민트 60,000원, 학습장치 80,000원, 먹다남은음식 100,000원. 판매가는 구매가의 1/4.
- 마을/스카우트는 1-3부터, 상점과 도구 착용은 첫 배지부터. 1-3 최초 클리어 시 티켓 한 장을 지급하며 반복 클리어·재접속·대화 다시보기로 중복 지급되지 않는다. 이후 티켓 1장으로 후보 3마리 중 1마리를 선택한다. 후보를 다시 열어도 재소비하지 않는다. 티켓은 지닌 도구로 사용할 수 없다.
- 관장 포켓몬은 직전 전투의 최고 레벨보다 5~8 높다. 기존 4개 실전 기술에 공격 성격과 열매를 더했다. 웅이의 꼬마돌/롱스톤은 모두 옹골참이며 실제 네이티브 피해 판정으로 검증했다.
- 1~7 지도는 동일한 최대 가로 1,100px, 2:1 프레임을 사용한다.
- 5장 늪지의 70개 칸별 CSS filter를 단순 배경색으로 교체했다. 모바일 전환에서 전장/움직이는 GIF 복제를 생략하고, 다음 전투 시작 시 이전 시뮬레이터를 해제한다. AI는 수만 개 후보를 배열에 쌓고 정렬하는 대신 최선의 후보 한 개만 유지한다.
- 검증: 26개 테스트, 좁은 브라우저 화면에서 5-1~5-10 진입/70칸 렌더링 및 5-1 턴 진행. 실제 휴대폰 브라우저 종료 현상은 이 환경에서 재현되지 않아 실기기 재확인이 필요하다.
- DB 스키마 수정은 필요 없다. PVP 번들은 최신 아이템 금지 규칙으로 다시 생성했다. Git 커밋/푸시 및 원격 함수 배포는 수행하지 않았다.

## 관리 · 스토리 후속 개편

- 학습장치는 비참여 생존 포켓몬 각각에게 획득 경험치의 40%를 추가 지급한다. 참여자의 경험치를 차감하지 않는다. 참여자가 학습장치를 착용해도 중복 지급하지 않는다. 3장 이후 경험치 배율을 먼저 적용한 실제 기본 경험치를 기준으로 계산한다.
- 레벨순은 높은 레벨부터, 동률은 도감 번호순이다. 상세 창의 트레이닝 버튼은 선택한 포켓몬과 함께 이동하고 이전 기술 검색을 초기화한다.
- 도구 관리: 진화의 돌/민트/도구 탭, 전체 보유 포켓몬 옆에 선출 여섯 칸을 배치한다. 두 목록 모두 같은 보유 도구를 사용하며 사용/착용/해제 후 수량과 상태를 함께 갱신한다.
- 티켓은 한 번에 여러 장 구매할 수 있으며 최대 보관 수량은 999장이다. 수량·소지금·보관 한도를 먼저 검증하고 결제한다.
- 이벤트가 이어지는 승리 결과창에는 확인 버튼만 표시한다. 1-3은 오박사 통화 → 티켓 획득 안내 → 마을·스카우트 잠금 해제 → 메인 화면으로 연결된다. 스카우트 첫 입장에 새 대사를 표시하며 지난 이야기에서도 다시 볼 수 있다.
- 사용자 대사의 ‘아,’, ‘아.’, ‘맞다,’ 같은 감탄 부분의 문장부호를 정리했다. 관장 포켓몬마다 위력 90 이상 공격기를 최소 하나씩 배치했다. 웅이의 두 포켓몬은 옹골참을 유지한다.

## 챕터별 스카우트 티켓 가격

1장 30,000원부터 새 챕터가 열릴 때마다 5,000원씩 인상한다. 2장 35,000원, 3장 40,000원, 7장 60,000원이다. 이전 지역을 다시 보아도 진행도 기준 가격이 유지된다. 상점 목록·상세·수량별 합계·실제 결제에 같은 가격 함수를 사용한다. 다른 도구 가격과 티켓 판매가는 유지한다.
