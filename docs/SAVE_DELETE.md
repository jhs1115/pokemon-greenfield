# 저장 파일 삭제

파일 선택 화면에서 내용이 있는 슬롯에 파일 삭제 버튼을 표시한다. 별도 확인창은 파일 번호와 포켓몬 미리보기를 보여주고 취소에 먼저 초점을 둔다. 삭제 확인 뒤에만 삭제한다. 처리 중에는 중복 실행과 파일 진입을 막고 실패하면 기존 내용을 유지한다. 현재 활성 슬롯을 지운 경우 메모리의 게임도 비워 후속 저장으로 되살아나지 않게 한다.

기기 저장은 해당 프로필과 슬롯의 localStorage 키만 제거한다. 계정 파일은 기존 save_game_slot RPC로 진행 데이터 전체를 {version:2,deleted:true}로 교체해 실제 게임 내용을 지우되 리비전은 증가시킨다. 화면/클라우드 read에서는 빈 파일로 취급한다. 이를 통해 오래된 다른 기기의 저장 요청이 리비전 충돌로 거절되고 삭제한 파일이 자동으로 복구되지 않는다. 같은 슬롯의 새 게임은 증가한 리비전으로 정상 저장된다. 별도의 SQL 실행이나 Edge Function 배포는 필요 없다.

클라우드 삭제는 업로드가 끝난 뒤 실행하며 슬롯 저장과 중복 삭제를 잠근다. 네트워크 오류, 다른 기기의 최신 저장, 계정 전환을 검사한다. 클라우드 슬롯과 별개인 기존 기기 파일은 자동으로 지우지 않는다.

검증: UI 취소/Escape/확인, 슬롯·프로필 격리, 메모리 초기화, 실패·재시도, 저장 중 삭제, 오래된 기기의 복구 방지, 새 게임 재생성, 계정 전환, 실제 PostgreSQL 리비전/RLS 검사를 포함한다. 실제 사용자 저장 파일은 테스트에서 삭제하지 않는다.

검증 결과: 전체 테스트 29개 통과. 별도 QA 프로필의 화면에서 취소 시 보존, 확인 후 새 게임 표시, 다른 파일 보존을 확인했다.
