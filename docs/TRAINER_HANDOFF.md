# 트레이너 연속전

2026-11-14.

- 첫 상대와 다음 상대 모두 기존 트레이너 도트를 먼저 보여 준다. 뒤로 물러남 → 실제 몬스터볼 도트 투척 → 개방 섬광 → 포켓몬 출전 순서로 재생한다.
- 출전 연출은 기본 2.1초이며 전투 2배속을 따른다. 연출 중 명령을 받지 않으며, 특성 표시는 출전 연출 다음에 재생한다. 화면을 나가거나 전투가 바뀌면 이전 연출이 조작 잠금·화면을 변경하지 않는다.
- 연속전의 중간 승리창과 확인 버튼을 없앴다. 250ms 뒤 다음 트레이너를 자동으로 불러오며 HP·상태·기술 PP·아이템 상태를 유지한다. 중간에는 클리어·돈 보상을 기록하지 않는다.
- 모든 트레이너를 쓰러뜨린 뒤 최종 결과를 표시한다. 후속 이야기가 있으면 확인으로 진행하고, 종료 시 같은 챕터의 지도와 해당 스테이지 선택으로 돌아온다. 2-5 습격 연결, 첫 웅이 도구 해금, PVP 대기실 복귀, 야생전 다음 전투 동작은 기존 흐름을 유지한다.
- 몬스터볼 원본: https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/items/poke-ball.png . 새 트레이너 그림은 생성하지 않았다.
