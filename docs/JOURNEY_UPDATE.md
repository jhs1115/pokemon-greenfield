## 코인·스카우트·상점

- 정상 승리마다 기본 코인 = 장 번호(1장 1, 2장 2, 3장 3, 4장 4). 기존 첫 클리어 추가 보상도 유지한다. 같은 전투 결과 ID에 대한 중복 보상은 거절한다.
- 스카우트 비용 = 10 + 5 × 완료한 장 수. 0/1/2/3/4장 완료 시 10/15/20/25/30코인이다. 후보를 이미 뽑았다면 다시 들어와도 재차 차감하지 않는다.
- 메인의 스카우트를 마을로 변경한다. 마을은 1장 완료 후 열리고 스카우트와 상점을 제공한다.
- 상점은 18타입 위력 1.2배 도구, 돌 5종, 학습장치, 열매와 먹다남은음식을 판매한다. 타입 도구 24, 돌 36, 학습장치 45, 먹다남은음식 60, 일반 열매 4/자뭉열매 8코인. 판매가는 구매가의 절반이다.
- 상점은 가방 수량만 판매할 수 있다. 착용 중 도구는 해제해야 판매할 수 있다. 재고/코인이 부족하거나 재고가 999개인 거래는 거절한다. 진화의 돌은 상점에서도 살 수 있으며 전투 드롭은 기존처럼 3장부터다.
- 스카우터의 일상 인사는 매 입장 때 바뀐다. 후보 공개 전에 짧은 캡슐 흔들림/빛 연출을 재생한다. 결과는 연출 전에 저장하므로 이동/새로고침으로 재차 비용을 내지 않는다.

## 관리·트레이닝

- 기본 엔트리는 6칸이다. 이전 3칸 저장을 불러오면 남은 3칸을 빈칸으로 늘린다. PVP의 6마리 중 3마리 선출 규칙은 유지한다.
- 포켓몬 관리에서 보유 포켓몬을 클릭하면 특성·도구·기술을 확인한다. 출전 버튼을 눌러야 엔트리에 들어간다. 원하는 엔트리 칸을 고르면 해당 칸에 배치하며, 빈칸이 있으면 기본적으로 빈칸에 추가한다.
- 도구 탭에서 모든 보유 포켓몬에게 착용/해제/돌 사용이 가능하다. 엔트리 포함 여부로 제한하지 않는다.
- 트레이닝의 한글 조합 중에는 입력 요소를 교체하지 않는다. 검색은 목록만 갱신하며 NFC·초성 검색을 지원한다. 기술을 클릭하면 설명과 물리/특수·위력·명중·PP가 표시되고, 가르치기 버튼으로 적용한다.
- 같은 화면에서의 목록 선택/교체 시 페이지 및 목록 스크롤을 보존한다. 파일 카드의 너비/높이를 같은 기준으로 고정한다.

## 전투와 확장

- 다시하기는 전투 결과창과 이미 클리어한 지도 스테이지에 둔다. 진행 중 전투 헤더에서는 제거한다.
- 날씨·필드 상태는 본가 엔진 판정과 동일한 스냅샷에서 읽는다. 비/눈/햇빛/모래와 4개 필드를 전장 내부의 옅은 효과와 조작 안내 위의 작은 이름표로 표현한다. 효과는 마우스 입력을 막지 않는다.
- 실제 캠페인은 7장 70전투다. 5장부터 4~5마리 적이 등장하고, 새 30전투 전부 실제 엔진 초기화와 턴 진행을 검증한다.

## 배포·검증

`npm test`는 기존 전투/저장/PVP/교환 검사와 새 이야기·경제·상점·검색·6마리 호환 검사를 포함한다. `npm run build:pvp`로 새 도구·날씨 데이터를 서버 번들에도 반영한다. JSON 저장 필드 확장이므로 추가 SQL 실행은 필요하지 않다.

`tests/journey-preview.html?scene=opening|brock|rocket|home|manage|training|bag|village|shop|files|field`는 실제 계정 저장을 읽거나 쓰지 않는 확인용 화면이다.
