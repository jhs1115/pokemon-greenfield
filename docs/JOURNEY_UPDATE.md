## 코인·스카우트·상점

- 정상 승리마다 기본 코인 = 장 번호(1장 1, 2장 2, 3장 3, 4장 4). 기존 첫 클리어 추가 보상도 유지한다. 같은 전투 결과 ID에 대한 중복 보상은 거절한다.
- 스카우트 비용 = 10 + 5 × 완료한 장 수. 0/1/2/3/4장 완료 시 10/15/20/25/30코인이다. 후보를 이미 뽑았다면 다시 들어와도 재차 차감하지 않는다.
- 메인의 스카우트를 마을로 변경한다. 마을은 1장 완료 후 열리고 스카우트와 상점을 제공한다.
- 상점은 18타입 위력 1.2배 도구, 돌 5종, 학습장치, 열매와 먹다남은음식을 판매한다. 타입 도구 24, 돌 36, 학습장치 45, 먹다남은음식 60, 일반 열매 4/자뭉열매 8코인. 판매가는 구매가의 절반이다.
- 상점은 가방 수량만 판매할 수 있다. 착용 중 도구는 해제해야 판매할 수 있다. 재고/코인이 부족하거나 재고가 999개인 거래는 거절한다. 진화의 돌은 상점에서도 살 수 있으며 전투 드롭은 기존처럼 3장부터다.
- 스카우터의 일상 인사는 매 입장 때 바뀐다. 후보 공개 전에 짧은 캡슐 흔들림/빛 연출을 재생한다. 결과는 연출 전에 저장하므로 이동/새로고침으로 재차 비용을 내지 않는다.

## 관리·트레이닝

- 기본 엔트리는 6칸이다. 이전 3칸 저장을 불러오면 남은 3칸을 빈칸으로 늘린다. PVP의 6마리 중 3마리 선출 규칙은 유지한다.
- 포켓몬 관리에서 보유 포켓몬을 클릭하면 특성·도구·기술을 확인한다. 출전 버튼을 눌러야 엔트리에 들어간다. 원하는 엔트리 칸을 고르면 해당 칸에 배치하며, 빈칸이 있으면 기본적으로 빈칸에 추가한다.
- 도구 탭에서 모든 보유 포켓몬에게 착용/해제/돌 사용이 가능하다. 엔트리 포함 여부로 제한하지 않는다.
- 트레이닝의 한글 조합 중에는 입력 요소를 교체하지 않는다. 검색은 목록만 갱신하며 NFC·초성 검색을 지원한다. 기술을 클릭하면 설명과 물리/특수·위력·명중·PP가 표시되고, 가르치기 버튼으로 적용한다.
- 같은 화면에서의 목록 선택/교체 시 페이지 및 목록 스크롤을 보존한다. 파일 카드의 너비/높이를 같은 기준으로 고정한다.

## 검색·상점 그림·기술음 수정

관리 검색은 IME 입력 확정까지 기다리지 않고 기존 입력창을 그대로 둔 채 목록만 실시간으로 거른다. 완성형/초성/호환 자모/분리된 NFD 한글과 영문 이름, 도감 번호를 지원하고 결과가 없으면 표시한다. 포켓몬과 도구 대상 검색에 동일하게 적용했다.

`assets/world/item-shop-v1.png`는 빌트인 image_gen으로 새로 만든 상점 전용 배경이다. 마을 상점 카드와 상점 내부 배너에 적용했다. 생성 방식과 전체 프롬프트는 `assets/world/item-shop-v1.prompt.txt`에 기록한다.

기술음은 이미지 이펙트 함수에 의존하지 않고 실제 전투 재생 단계에서 타격마다 직접 호출한다. 음원의 피크가 낮아도 음량이 보정되도록 하고(최대 8배, 목표 피크 0.65), 기술음 재생 중 BGM을 40%로 낮춘 뒤 복구한다. 확인음이 기술음을 끊지 않는다. 기본 효과음은 24%이며 구버전 음량은 버전 6에서 한 번 복구하고, 이후 새로 선택한 음량/전체 음소거는 저장한다. 새 리소스 캐시 버전을 적용했다.

- 진행 순서는 유지하고 70개 스테이지의 좌표를 완성된 그림 속 길·광장·다리에 맞췄다. `layout.json`에 좌표를 기록하고 `python scripts/check-route-ground.py`로 바닥색을 확인한다. 그림 위에 작은 표지판을 배치하고 마우스 진입/키보드 포커스 시 해당 위치 옆에 포켓몬 이름·레벨·기존 스프라이트가 뜬다. 터치에서는 탭으로 같은 미리보기를 볼 수 있다. 하단 고정 몬스터 목록은 제거하고 선택/출발만 유지한다. 선택할 때 지도를 다시 렌더링하지 않아 화면이나 포커스가 튀지 않는다.

### 스테이지 위치 재검토

7장 전체 70개 지점을 최종 v3 그림의 원본 픽셀 좌표로 다시 배치했다. 일반 지점은 길 중앙, 관장전은 체육관 문 앞마당, 4-8은 로켓단 거점 입구로 맞춘다. 5-6은 좁은 다리 대신 건넌 뒤 공터에 놓고, 6-6은 번호판이 화단을 가리지 않도록 사무실 옆길에 둔다. `layout.json`의 `reviewedPixelCenters`에 원본 좌표를 남긴다.

## 1장 대본 리메이크 반영

사용자가 작성한 대본으로 연구소/첫 배틀/웅이 첫 만남/체육관/승리/오박사 선물과 후속 뉴스/스카우터 소개를 교체했다. 1-1과 1-4는 최초 입장에만 재생하며 지난 이야기에서 다시 볼 수 있다. 웅이 재도전과 승리 대사는 별도 처리한다. [CHAPTER_ONE_SCRIPT.md](CHAPTER_ONE_SCRIPT.md)가 실제 반영 대본이다.

대괄호는 화면에서 제거하고 안의 글자만 붉게 표시한다. 생각 대사는 회색으로 표시한다. 한 글자 출력 중에도 색을 유지하고 Enter 첫 입력은 완성, 다음 입력은 진행한다. 아나운서 장면은 NPC를 숨기며 실제 뉴스 인물 스프라이트를 새로 만들지 않는다. 웅이 승리 대사 후 오박사 선물/뉴스로 연결하고 학습장치 2개는 기존 지급 플래그로 한 번만 지급한다. 선물 장면 중 재접속과 스킵도 중복 지급하지 않는다. 관리·트레이닝 첫 진입 대사와 회상 항목은 제거했다.

### 1장 문법과 기술 검색 후속 수정

1장의 맞춤법·띄어쓰기를 교정하되 사용자 개그 대사(넌 디졋다, 개패드릴게요, 시계 풀게 등)는 유지한다. 기술 검색은 IME 조합 중에도 현재 문자열로 기술 목록만 갱신한다. 조합 종료 이벤트를 기다리는 동안 결과가 멈추지 않으며 Enter/검색/변경 이벤트에서도 갱신한다. 입력창과 기술 장착 상태는 검색으로 바뀌지 않는다.

## 스토리 난이도 소폭 상향

- 1-1~1-5 레벨은 유지한다. 1-6~4-10은 적 레벨 +1, 5~7장은 +2. 2장 로켓단 습격도 +1. 지도와 실제 전투는 같은 encounter 레벨을 사용하며 PVP 고정 50에는 적용하지 않는다.
- 일반 적은 자기 레벨에서 배울 수 있는 흑안개·클리어스모그·도발·울부짖기·날려버리기가 있으면 기술 후보에 한 자리를 확보한다. 관장의 지정 기술 구성은 유지한다.
- AI는 현재 공개된 상대 랭크가 쌓이면 초기화·도발·강제 교체의 가치를 높이고, 자기 랭크업도 크게 쌓여 있으면 흑안개 사용을 피한다. 이미 랭크가 중립이면 흑안개를 반복하지 않는다. 강제 교체는 상대에게 살아 있는 대기 포켓몬이 있을 때만 고려한다.
- 공격으로 쓰러뜨릴 수 있으면 공격 점수를 높이며, 현재 상대 칸을 맞히는 후보 중 인접 이동 칸도 덮는 범위를 조금 선호한다. 플레이어의 아직 확정되지 않은 명령은 읽지 않는다.
- 경험치 공식·보상·플레이어 기술 효과는 유지한다. 원본 랭크업 효과를 너프하지 않고 상대의 대응과 레벨로 조정한다. 실제 네이티브 흑안개가 +4 공격 랭크를 지우는 AI 전투 테스트를 추가했다.

## 2장 대본과 2-5 연전

- 사용자 대본으로 2-1/2-2/습격전 전후/2-8/이슬이 체육관 전후를 교체하고 재도전 대사를 분리한다. `docs/CHAPTER_TWO_SCRIPT.md`가 대본이다. 회색 지문과 붉은 단서를 유지하고, 2-8은 웅이와 이슬이를 동시에 표시해 발화자만 밝게 한다.
- 2-5 첫 승리 뒤 로켓단 습격은 남은 HP, 기절 여부, 주요 상태이상과 수면 카운터, PP, 랭크, 지닌 도구, 출전 포켓몬을 이어받는다. 기존 습격 상대는 2-5보다 높은 19/20/20레벨이다. 일시적 날씨/필드/풀죽음 같은 턴 단위 효과는 새로운 전투에서 초기화한다.
- 체크포인트는 `rocketCarry`로 저장·정규화해 재접속 뒤 지도 습격 버튼에서도 같은 상태로 진행한다. 이전 파일처럼 체크포인트가 없는 미완료 습격은 2-5부터 진행한다. 습격에서 패배하면 체크포인트를 지우고 재시작/다시하기는 2-5로 돌아간다. 이미 얻은 경험치·2-5 보상은 기존 전투 규칙대로 유지하며 2-6은 습격 승리 전까지 잠근다.
- 습격 승리 뒤 이슬이가 개입하는 후일담을 재생하며, 지난 이야기에도 전후 장면을 따로 제공한다. 이슬이 승리 후 블루배지 대사도 추가한다. 과거 저장을 초기화하지 않는다.

## 관장전 레벨·실전 기술 재구성

모든 관장 포켓몬을 직전 스테이지 최고 레벨보다 3~5레벨 높게 조정했다. 팀 종은 유지하고 각 포켓몬에 실제 습득 가능한 기술 네 개를 지정한다. 기존 본가 FRLG 기술 고정은 사용자 요청에 따라 해제하고, 주력기/약점 견제/회복/상태이상/랭크 초기화/방어막 등 관장별 전술을 구성했다. 전체 레벨과 기술은 [GYM_BALANCE.md](GYM_BALANCE.md)를 따른다. AI에 방어막 평가와 풀묶기의 체중 기반 위력 평가를 추가했다. 일반 스테이지와 PVP 레벨 규칙은 이 변경의 대상이 아니다.
