# 9장 — 폭주의 끝

9-1 하나로 구성한다. 8-5 클리어 후 이동할 수 있다. 폐허 지도 가운데 기존 뮤츠 도트가 서 있고, 아래의 9-1 지점에서 결전에 들어간다.

## 전투

- 뮤츠 Lv.100, 겁쟁이, 프레셔, 먹다남은음식. 노력치 0.
- 시작 시 공격·방어·특수공격·특수방어·스피드 +1. 명중·회피는 변경하지 않는다.
- 사이코브레이크 / 화염방사 / 냉동빔 / 파동탄. 네 기술 모두 특수기이며 서로 다른 타입이다.
- 전용 Mewtwo BGM은 다른 전투와 별도로 재생한다. 기존 낮은 음량/음소거 설정을 존중한다.

## 구출과 저장

최종 진화형 스타팅 이름은 이상해꽃·리자몽·거북왕 중 선택한 파트너에 맞춰 치환한다. 연출 때문에 보유 포켓몬을 강제 진화시키거나 교체하지 않는다. 구출 장면의 합류 페이지 또는 건너뛰기 완료 시, 한 번만 랜덤 성격 Lv.85 뮤츠를 지급한다. 팀에 빈 칸이 있으면 합류시키며, 가득 찼다면 보유 목록에 추가한다. 이미 뮤츠가 있다면 개체·레벨·성격·이로치·기술을 덮어쓰지 않는다. 승리 후 중단한 파일은 9-1을 다시 열면 구출 장면부터 이어진다. 지난 이야기 재감상은 보상을 지급하지 않는다.

9-1 클리어 이후 리그(10장 이상)는 레벨캡을 적용하지 않는다. 현재 성장 한계 100레벨은 유지한다.

## 그림과 연출

Built-in image_gen으로 폐허 지도·눈·새벽 배경·실제 누운 뮤츠·손잡기 클로즈업을 제작했다. 누운 컷은 새로 그린 옆으로 쉰 자세를 사용하며, 같은 그림 위에 눈을 뜨는 디테일을 결합했다. 뮤츠와 목걸이 파괴를 함께 그리는 생성 요청은 거부되어, 해당 컷은 기존 뮤츠 도트와 목에 결합한 SVG 제어장치·파편·충격광으로 구현했다. 장치 단독 매크로 그림은 보존하지만 최종 파괴 컷에는 사용하지 않는다. CLI 이미지 생성은 사용하지 않았다.
