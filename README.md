# 포켓몬 그린필드

HTML/CSS/JavaScript로 만든 로컬 타일 턴제 게임입니다. 런타임 빌드 없이 실행합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

http://127.0.0.1:8765/ 에서 게임 시작 → 파일 1~3 → 튜토리얼을 진행합니다. 기본 저장은 브라우저/주소별 localStorage이며 기존 파일을 유지합니다. Supabase 공개 설정을 연결하면 로그인 후 계정별 클라우드 저장을 사용합니다.

## 현재 구현

- 1세대 151종, 메뉴의 기존 애니메이션 도트와 전투의 원본 PNG 도트.
- 4장 40스테이지와 서로 다른 경로 지도: 숲길 / 강가 / 항구 / 정원.
- 1-10 웅이, 2-10 이슬이, 3-10 마티스, 4-10 민화. 첫 도전 3개 대사, 이후 1개 대사와 전용 체육관 배경.
- 2-5 후 로켓단 3마리 습격전, 3-3 / 3-8 로켓단 전투. 본격 스토리 본문은 이후 추가할 수 있도록 분리.
- 3마리 선출·1마리 출전, 모든 이동 후 우선도/스피드에 따라 기술 실행.
- 실제 본가 데이터 기반 Lv.5 초기 기술 / 성장 / 진화. 비최종 진화는 현재 레벨까지의 레벨업 기술, 최종 진화는 종별 습득 가능한 전체 기술과 일반/숨겨진 특성 선택.
- Pokémon Showdown 기반 `@pkmn/sim` 9세대 판정: 물리/특수 분리, 명중·회피, 상태이상, 조건부 기술, 특성, 지닌 도구.
- 최대 5칸 타격, 초반 공격은 1~3칸, 상대 대상 변화기는 긴 사거리. 기술 이름·상성·랭크 변화·특성 배너.
- 웅이 클리어 후 도구 해금/학습장치 2개 1회 지급. 업데이트 전 클리어 파일도 인식. 관리에서 도구 장착, 열매 소비·타입 강화·학습장치 경험치 분배, 가끔 도구 드롭.
- 스카우트 10코인, 기본형 3후보 중 1마리. 전설/환상 제외, 스타팅/미뇽 계열 레어 가중치. 영입 기본 Lv.5 → 1장 완료 Lv.8 → 2장 완료 Lv.12.
- 신규 0코인, 튜토리얼 완료 10코인. 장이 높아질수록 클리어/반복 코인 보상 증가.
- 스카우트 가게/실내 트레이닝/관리 배경, 밝은 UI, 화면 전환·NPC 움직임·진화 연출.
- 기존 메뉴 음악 복구, 실제 포켓몬 RBY 트레이너전 음악 한 곡을 모든 전투/관장전에 공통 사용. 다운로드한 669개 기술음과 작은 확인음. ♪에서 음악/효과음/음소거 및 작은 음원 출처 확인.
- 상대도 본가 특성 적용. 잠듦/얼음은 이동 금지, 마비는 이동/공격 공통 12.5% 행동 불가 판정.
- 3장부터 진화의 돌 드롭, 관리의 별도 도구 탭에서 ‘도구 사용’ 후 엔트리 포켓몬을 선택해 소모 진화. 3~4장 경험치 1.5배.
- 관장 기술은 FRLG 실제 파티 데이터 기준. AI는 약점·면역·상태이상·회복·거리 판단.
- 전투 타일 정사각형 비율 고정, 배경/도트 비율 유지, 블러 없는 220ms 화면 교차 전환.
- 관리 화면은 포켓몬/도구 탭 분리. 도구 선택 → 사용/착용 → 엔트리 대상 선택, 해제 시 가방 반환.
- 상대 특성은 오른쪽, 내 특성은 왼쪽. 기술 속성은 카드 오른쪽 위.
- 2~4장 지도 노드 좌표 유지, 직선 연결 경로.
- PVP는 공사중.

## 주요 파일

- `game-state.js`: 저장 호환, 성장, 선출, 스카우트 가중치, 도구/경험치 분배, 40스테이지 보상
- `stages.js`, `chapter-maps.js`, `campaign-ui.js`: 캠페인/로켓단/체육관/도구 해금과 메뉴
- `native-combat.js`, `assets/vendor/pkmn-sim.js`: 실제 전투 판정
- `app.js`, `engine.js`: 타일 전투/범위/AI
- `audio.js`, `assets/audio/move-sounds.js`: 조용한 음악/기술 파일 효과음 재생
- `journey.js`, `menus.js`, `battle-feedback.js`: 튜토리얼/트레이닝/연출
- `items.js`: 도구 이름/설명

규칙·자료·제약은 [docs/GAME_RULES.md](docs/GAME_RULES.md), 음악 출처는 [assets/audio/SOURCE.md](assets/audio/SOURCE.md), 그림 출처는 `assets/world/SOURCE.md`, `assets/trainers/SOURCE.md`를 참고하세요.

## 검증 / 개발

```powershell
npm ci
npm test
npm run build:sim
```

`npm`이 PATH에 없을 경우 이 작업 환경에서는 `node tools/npm/bin/npm-cli.js test`를 사용할 수 있습니다. 배포된 번들은 게임 실행 시 재빌드할 필요가 없습니다.

`tests/campaign-preview.html`과 `tests/visual-scenes.html`은 저장 파일을 쓰지 않는 개발용 장면 확인 페이지입니다. 실제 플레이는 루트 페이지를 사용합니다.

엔진: https://github.com/pkmn/ps (MIT). Jua 글꼴: https://github.com/google/fonts/tree/main/ofl/jua (OFL). Pokemon 데이터/기존 도트/울음소리: PokéAPI 및 pret 저장소. 캐릭터와 환경 생성 이미지의 전체 프롬프트·도구 방식은 각 `assets/*/SOURCE.md`에 기록합니다.


## Supabase 계정 / 클라우드 저장

이메일 로그인·회원가입·비밀번호 재설정, 계정별 저장 슬롯 3개, 빈 슬롯에 기기 파일 가져오기, 자동 저장·재시도·동시 수정 충돌 처리를 구현했습니다. `supabase-config.js`의 공개 URL/Publishable key와 `supabase/schema.sql` 실행이 필요합니다. 설정 전에는 기존 기기 저장으로 동작합니다. [연결 절차와 범위](docs/SUPABASE_SETUP.md)를 참고하세요. 교환/PVP와 서버 권위 재화 관리는 다음 단계입니다.
