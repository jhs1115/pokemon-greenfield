- `routes/chapter-1-v2.png` through `routes/chapter-7-v2.png`: seven original wide pixel regions, generated separately with the built-in image_gen tool on 2026-11-08. The old square atlas is retained as an earlier asset and is no longer used. No Pokemon sprites were generated.

Runtime uses these v3 images; earlier square/v2 artwork is retained as versioned source.
