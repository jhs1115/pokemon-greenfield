# Environment artwork

- `home-scenes.png`: generated with the imagegen skill for this project, 2026-11-01. Environment-only 2×2 atlas: forest adventure trail, laboratory cottage, scout camp meadow, outdoor training court. No Pokemon or trainer artwork generated. Original generated file retained under Codex generated_images; copied locally for offline runtime.
- `kanto-route.svg`: project-authored code-native pixel map, generated by `scripts/prepare_route.py`.
- Pokemon layered over these scenes: existing downloaded sprites, unchanged.

- `title-adventure.png`: dedicated opening screen environment, generated with the built-in imagegen tool on 2026-11-01. Original forest, lake and village scenery without Pokemon or text; existing starter sprites and HTML lettering are layered over it. Full prompt/tool mode: [title-adventure.prompt.txt](title-adventure.prompt.txt).

- `interiors.png`: built-in imagegen original environment-only 2×2 atlas (scout shop / training room / neutral lounge / river clearing). Full prompt: [interiors.prompt.txt](interiors.prompt.txt).
- `gyms.png`: built-in imagegen environment-only 2×2 atlas (rock / water / electric / grass gyms). Full prompt: [gyms.prompt.txt](gyms.prompt.txt).
- `chapter-2.svg`, `chapter-3.svg`, `chapter-4.svg`: code-native pixel maps with different node coordinates/curved routes, generated by `scripts/prepare_campaign.py`.

- `pvp-home-v1.png`, `trade-home-v1.png`: generated with the built-in imagegen tool on 2026-11-03. Original environment-only outdoor battle stadium and cozy exchange laboratory. Full prompts/tool mode: `pvp-home-v1.prompt.txt`, `trade-home-v1.prompt.txt`. Pokemon shown in the menu are existing downloaded sprites layered in HTML; no Pokemon sprites were generated. Original PNGs remain in Codex generated_images; runtime copies are stored in this folder.

- `item-shop-v1.png`: original environment-only item shop, created with the built-in image_gen tool on 2026-11-06. Potions, stones, mint herbs and a wooden counter; no Pokemon or trainer sprites generated. Used by the village shop card and the shop interior banner. Exact prompt/tool mode: [item-shop-v1.prompt.txt](item-shop-v1.prompt.txt).

- `route-atlas-v1.png`: generated with built-in image_gen on 2026-11-08. Original environment-only top-down pixel map atlas (2 columns × 4 rows); chapters 1–7 use forest, river, harbor, garden, safari, city and island cells. Cell 8 is unused. Existing Pokemon sprites are only displayed in HTML previews. Full prompt/tool mode: [route-atlas-v1.prompt.txt](route-atlas-v1.prompt.txt).

- `routes/chapter-1-v2.png` through `routes/chapter-7-v2.png`: seven original wide pixel regions, generated separately with the built-in image_gen tool on 2026-11-08. Each map is 1774×887, with a continuous route and small buildings. Seventy marker locations were manually selected after inspecting the final artwork, on walkable paths, bridge decks and entrance courtyards. Exact per-map prompts are the corresponding `.prompt.txt` files. `routes/layout.json` records the reviewed coordinates and image dimensions. The old square atlas is retained as an earlier asset and is no longer used. No Pokemon sprites were generated.

- `routes/chapter-1-v3.png` through `chapter-7-v3.png`: built-in image_gen edits of the wide v2 maps on 2026-11-08, preserving route geometry while differentiating plains / farmland river / industrial port / golden garden town / earthy wetland / dense gray city / volcanic mainland coast. West/east continuation roads open the regions to a connected journey. Per-image `.prompt.txt` files contain exact edit prompts and tool mode. Runtime uses these v3 images; earlier square/v2 artwork is retained as versioned source.

- `oak-laboratory-v1.png`: original environment-only Oak lab background generated with built-in image_gen on 2026-11-08. Reference: the official Pokemon Let’s Go [Professor Oak page](https://www.pokemon.co.jp/ex/pika_vee/character/180713_03.html), plus mainline FireRed/LeafGreen lab arrangement (bookcases, computers and three starter Poke Balls). A newly illustrated scene, not a downloaded game screenshot. Exact generation prompt/tool mode: [oak-laboratory-v1.prompt.txt](oak-laboratory-v1.prompt.txt). The story lab now uses this dedicated image; exchange artwork remains separate.
