# Type badge source

Existing Pokemon X/Y type badge PNGs, type IDs 1 through 18.

Source: https://github.com/PokeAPI/sprites/tree/master/sprites/types/generation-vi/x-y

Repository documentation: https://github.com/PokeAPI/sprites#types

Downloaded images are used unchanged. The images contain English type names; the game's image alt text and tooltips use Korean names. These are type identifiers, not a type effectiveness chart.

Re-download with `python scripts/collect_type_icons.py`.
